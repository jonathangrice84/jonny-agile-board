# Jonny × theclaw — Agile Board

Phone-friendly agile board hosted on **GitHub Pages**.

- Board UI: `docs/index.html`
- Data: `docs/board.json`

## Workflow
- theclaw updates `docs/board.json` via commits/PRs.
- Jonny approves actions in Telegram (e.g., `Approved ✅ #3`).
- After approval, theclaw executes and moves the card across columns.

## Local preview
Open `docs/index.html` in a browser.

## Publish
GitHub Pages should be enabled for the `main` branch, `/docs` folder.
